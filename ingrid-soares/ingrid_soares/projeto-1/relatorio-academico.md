# Relatório Acadêmico: Agente de Extração de Metadados Open Source com Conformidade à LGPD

## 1. Introdução
Este projeto foca na automatização da extração de metadados de arquivos em repositórios, garantindo conformidade com a LGPD através de uma arquitetura modular e segura.

## 2. Checklist de Conformidade do Projeto
1. **Estrutura de Pastas:** Organizada conforme diretrizes acadêmicas.
2. **Conformidade LGPD:** Implementação de regras de filtragem para anonimização de dados pessoais contidos nos metadados.
3. **Extração Automática:** Uso de bibliotecas de extração para processamento em lote.
4. **Rastreabilidade:** Logs de processamento para auditoria de conformidade.
5. **Integração:** Fluxo de extração -> processamento (limpeza) -> armazenamento seguro.

## 3. Justificativa Técnica
A automatização reduz o esforço manual de conformidade, eliminando o erro humano ao tratar dados sensíveis (PII) extraídos de documentos.

## 4. Considerações Finais
O sistema provou a eficácia da automação na gestão de dados sensíveis, garantindo que metadados não conformes sejam tratados antes da indexação ou armazenamento.
