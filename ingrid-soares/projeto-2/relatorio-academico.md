# Relatório Acadêmico: Sistema Integrado de Cibersegurança baseado em Machine Learning

## 1. Introdução
Este projeto apresenta a implementação de um sistema de detecção de anomalias (phishing) utilizando técnicas de aprendizado de máquina, focado na prevenção automatizada de ameaças em tempo real.

## 2. Checklist de Conformidade do Projeto
1. **Pipeline de Dados:** Ingestão de dados de phishing para treinamento do modelo.
2. **Modelo de ML:** Classificação de URLs maliciosas versus legítimas.
3. **Métricas de Performance:** Uso do MLFlow para rastreamento de acurácia, precisão e recall.
4. **Integração:** Pipeline contínuo (CI/CD) com análise automatizada de logs.
5. **Observabilidade:** Logs de treinamento e inferência monitorados via MLFlow.

## 3. Justificativa Técnica
A utilização de ML permite a detecção de padrões complexos que seriam invisíveis para sistemas baseados em regras estáticas (assinaturas), aumentando a resiliência contra ataques emergentes.

## 4. Considerações Finais
A automação da detecção de ameaças com ML demonstrou ser uma ferramenta poderosa para o SOC, permitindo reduzir o tempo de resposta e aumentar a acurácia das decisões de bloqueio.
